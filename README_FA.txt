# ماجراجوی کلاس چهارم - پروژه Android

## محتویات
این پروژه یک اپ اندرویدی ساده است که بازی آموزشی HTML را داخل WebView اجرا می‌کند.
پیشرفت و سکه‌ها با localStorage روی همان دستگاه ذخیره می‌شوند.

## ساخت APK
1. Android Studio را نصب کنید.
2. از File > Open پوشه AdventureGrade4 را انتخاب کنید.
3. منتظر بمانید Gradle Sync تمام شود.
4. از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
5. فایل APK در مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

## نکته
این پروژه برای شروع و نمونه اولیه است. قبل از انتشار عمومی، محتوا و سازگاری نسخه‌های مختلف اندروید باید آزمایش شوند.
